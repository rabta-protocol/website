Capabilities

six core pillars · wire-level specs
ed25519

Signed events

Every event is canonical JSON, hashed with SHA-256 and signed with Ed25519. Identity is a keypair — no accounts, no sessions, no passwords.

RFC 8785 Keypair identity 100 KB max
spec
query

Live queries

Poll any collection through a typed JSON query. Filter by labels or owner, and page results with an opaque cursor.

Cursor paging 10 labels HTTP poll
spec
sha-256

Content-addressed blobs

Uploads return their SHA-256, dedupe automatically and expire with the signed events that claim them. Encrypt client-side and the relay only sees ciphertext.

Auto dedup Event-pinned Zero knowledge
spec
rust · sqlite

Yours to run

One Rust binary, one SQLite file, one container. No database server, no cloud dependency, no per-user pricing — deploy it anywhere.

Rust 2024 WAL mode Single binary
spec
merkle · xor

Autonomous peer sync

Decentralized multi-node replication. Nodes reconcile diverged event sets in milliseconds using a 256-bucket XOR folding Merkle walk without central coordinators.

256 buckets XOR folding Multi-node
spec
ring · sandbox

Machine anti-spam

Engineered to protect the host machine: a 64k-entry in-memory ring buffer drops spam in microseconds, backed by battery token accounting and isolated staging.

64k ring <5µs Battery tokens 10% staging
