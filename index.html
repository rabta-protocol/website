Capabilities

six core pillars
ed25519

Signed events

Every event is canonical JSON, hashed with SHA-256 and signed with Ed25519. Identity is a keypair — no accounts, no sessions, no passwords.

Canonical JSON Keypair identity 100 KB max
query

Live queries

Poll any collection over HTTP query parameters. Match exact collections or globs, filter by labels or owner, and page results with an opaque cursor.

Cursor paging Collection globs ETag 304
sha-256

Content-addressed blobs

Uploads are sealed RABTA1 containers: they return their SHA-256, dedupe automatically and expire with the signed events that claim them. The relay only sees ciphertext.

RABTA1 Auto dedup Zero knowledge
rust · sqlite

Yours to run

One Rust binary, one SQLite file, one container. No database server, no cloud dependency, no per-user pricing — deploy it anywhere.

Rust 2024 WAL mode Single binary
merkle · xor

Autonomous peer sync

Decentralized multi-node replication. Nodes reconcile diverged event sets in milliseconds using a 256-bucket XOR folding Merkle walk without central coordinators.

256 buckets XOR folding Multi-node
ring · sandbox

Machine anti-spam

Engineered to protect the host machine: a 64k-entry in-memory ring buffer drops spam in microseconds, backed by a 1M-unit battery with read-only and sync-disabled tiers.

64k ring <5µs 1M units 3 tiers
